# Appendix C. Employer Evaluation Scorecard

Use this scorecard to evaluate whether an organization can productively employ high-leverage post-LLM capability.

Score each dimension from 1 to 5.

## C1. Problem readiness

| Dimension | Score | Evidence |
|---|---:|---|
| A real workflow or outcome is identified |  |  |
| The current baseline is measurable |  |  |
| The problem has an accountable owner |  |  |
| The organization distinguishes prototype from production |  |  |

## C2. Sponsorship

| Dimension | Score | Evidence |
|---|---:|---|
| Executive sponsor exists |  |  |
| Sponsor can allocate budget and access |  |  |
| Sponsor accepts process change, not only tooling |  |  |
| Technical and business owners are aligned |  |  |

## C3. Authority and governance

| Dimension | Score | Evidence |
|---|---:|---|
| Tool and data access can be scoped |  |  |
| Approval paths are explicit |  |  |
| Security and compliance engage early |  |  |
| Consequential actions can be receipted |  |  |
| Refusal and shutdown are supported |  |  |

## C4. Evaluation readiness

| Dimension | Score | Evidence |
|---|---:|---|
| Acceptance criteria exist |  |  |
| Representative cases are available |  |  |

## C5. Role readiness

| Dimension | Score | Evidence |
|---|---:|---|
| Reporting line fits the cross-functional scope |  |  |
| Authority matches expected outcomes |  |  |
| Leveling recognizes architecture and leverage |  |  |
| The role is not isolated innovation theater |  |  |

## C6. Candidate experience

| Dimension | Score | Evidence |
|---|---:|---|
| Interview measures actual role behavior |  |  |
| Agent-assisted work is evaluated transparently |  |  |
| Portfolio evidence is inspected |  |  |
| Recruiter can explain the role |  |  |
| Decision timelines and next steps are clear |  |  |

## Interpretation

- **100–120:** strong readiness; verify local details.
- **80–99:** promising; identify two repairable constraints.
- **60–79:** material risk of underutilization or stalled delivery.
- **Below 60:** role may be aspirational rather than operational.

A low score is not automatically a refusal. It is a basis for an explicit decision.

## Candidate questions

Ask:

1. Which workflow would this role own first?
2. Who carries the outcome and budget?
3. What prevents the current AI work from reaching production?
4. How will the first ninety days be evaluated?
5. Which systems and data can the role access?
6. Who approves consequential agent actions?
7. How are model, review, and failure costs measured?
8. What will remain with the organization if the first project succeeds?
9. How does the interview process sample the actual work?
10. What would cause the company to stop or narrow the initiative?
