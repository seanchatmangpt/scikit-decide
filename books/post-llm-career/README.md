# The Post-LLM Career

A complete mdBook manuscript by Sean Chatman about working, hiring, and building leverage when intelligence is abundant.

## Read

Start with [`src/SUMMARY.md`](src/SUMMARY.md) or [`src/README.md`](src/README.md).

## Build

```bash
mdbook build
mdbook serve --open
```

The generated HTML output is intentionally not committed. The canonical artifact is the Markdown source graph under `src/`.
