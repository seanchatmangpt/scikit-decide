# Crown Gap Hardening

AutoFDE-Lab owns experimental reasoning over admitted evidence. It preserves candidate portfolios, runs falsification, and produces admission candidates; it does not own process-science truth or execution authority.

Hard laws:

- wasm4pm-derived process facts cross the boundary through an explicit evidence contract;
- local conformance helpers are bounded falsifiers, never a second authoritative process engine;
- candidate selection cannot bypass GymAct consequence testing;
- planning receipts are not execution receipts;
- exact-subject identities are mandatory at every admission edge.
